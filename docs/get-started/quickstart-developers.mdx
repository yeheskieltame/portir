---
title: "Quickstart for developers"
description: "Plug Portir into Claude or your own agent in one command, through MCP."
---

Portir is a hosted product. You integrate with it through its **MCP server**, its **x402 / A2A** endpoints, or its **public contracts** on BNB Chain. There is nothing to install or run.

<Steps>
  <Step title="Add the MCP server">
    <Tabs>
      <Tab title="Claude Code">
        ```bash
        claude mcp add portir --transport http https://agent.portir.xyz/mcp
        ```
      </Tab>
      <Tab title="Claude Desktop / Cowork">
        Settings → Connectors → Add custom connector → URL `https://agent.portir.xyz/mcp`.
      </Tab>
      <Tab title="Any MCP client">
        ```json
        {
          "mcpServers": {
            "portir": { "type": "http", "url": "https://agent.portir.xyz/mcp" }
          }
        }
        ```
      </Tab>
    </Tabs>
  </Step>
  <Step title="Ask">
    *"Is now a good time to buy TSLA on-chain?"* calls `get_fair_price` and answers with the Guard's verdict and reason.
  </Step>
  <Step title="Act">
    *"Set up $30 weekly NVDA, only when fair."* calls `prepare_dca_plan` and returns **unsigned calldata**. The user's wallet signs; Portir never signs for anyone.
  </Step>
</Steps>
